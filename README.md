# NumPy Essentials & Scientific Computing Guide

An interactive reference notebook covering essential operations, array manipulations, and scientific computing patterns in NumPy.

---

## 📋 Overview

This repository contains an introductory and practice notebook (`numpy.ipynb`) covering core features of the NumPy library in Python. It serves as a practical guide for data science, machine learning, and numerical computing workflows.

---

## 🛠️ Key Topics Covered

- **Array Creation & Initialization**
  - Constructing 1D, 2D, and $N$-dimensional arrays from Python lists and built-in functions (`np.zeros`, `np.ones`, `np.arange`, `np.linspace`).
- **Array Attributes & Inspection**
  - Checking array dimensions (`ndim`), shapes (`shape`), sizes (`size`), and data types (`dtype`).
- **Indexing & Slicing**
  - Accessing specific elements, row/column slicing, sub-array extraction, and multi-dimensional slicing tricks.
- **Vectorized Operations & Ufuncs**
  - Element-wise arithmetic, mathematical functions (trigonometric, exponential, logarithmic), and broadcasting concepts.
- **Reshaping & Manipulation**
  - Altering dimensions with `.reshape()`, flattening arrays (`.ravel()`, `.flatten()`), and stacking/splitting arrays (`vstack`, `hstack`).
- **Aggregation & Statistical Functions**
  - Computing sums, means, standard deviations, minimums, and maximums across specific axes.
- **Boolean Indexing & Masking**
  - Filtering data based on conditional statements and logical operators.
